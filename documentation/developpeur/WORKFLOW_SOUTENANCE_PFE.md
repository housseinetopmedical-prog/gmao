# Workflow de la plateforme - version soutenance PFE

## 1. Workflow ultra simple sur une seule page

La plateforme suit un workflow principal de maintenance biomédicale en 8 étapes.

1. Le client ou la facturation crée une demande d'intervention.
2. L'ADV qualifie la demande.
3. Le responsable technique affecte le technicien.
4. Le technicien ou RT réalise le diagnostic.
5. Si besoin, l'ADV prépare et envoie un devis au client.
6. Le technicien réalise la réparation.
7. Si une pièce manque ou MAJ ou nouvelle installation, le technicien ou le RT enregistre ce qui manque et envoi à l'import en cas de besoin de piéce à importer.
8. Le technicien ou RT clôture techniquement en choisissant matériel réparé pret à livré ou irreparable et ils enregistrent les actions réalisés et le montant de réparation, puis l'ADV clôture administrativement et envoie la satisfaction client et si le ticket est entrée par la facturation un ticket de sortie va etre disponible dans son espace.
9. le responsable d'appel d'offre enregistre les infos de marchés et les visites préventives et correctives tout doit etre visible par le technicien.
## 2. Résumé global à dire à l'oral

La plateforme couvre tout le cycle SAV biomédical :

- demande d'intervention ;
- qualification ADV ;
- décision garantie ou hors garantie ;
- devis client si nécessaire ;
- affectation technique ;
- diagnostic et réparation ;
- gestion des pièces ;
- clôture administrative ;
- satisfaction client.

En parallèle, la plateforme gère aussi :

- les marchés et visites d'appels d'offre ;
- la messagerie interne ;
- la facturation ;
- l'historique des tickets ;
- le suivi client.

## 3. Schéma acteur par acteur

### Client

Rôle du client dans la plateforme :

- créer une demande d'intervention ;
- joindre les informations du matériel ;
- ajouter les documents ou médias ;
- suivre l'avancement ;
- valider ou refuser le devis ;
- répondre à l'enquête de satisfaction.

### ADV

Rôle de l'ADV dans la plateforme :

- recevoir les demandes d'intervention ;
- qualifier les demandes ;
- vérifier les informations administratives et de garantie ;
- préparer le devis si le dossier est hors garantie ;
- envoyer le devis au client ;
- effectuer la clôture administrative et demander la satisfaction.

### Responsable technique

Rôle du responsable technique dans la plateforme :
- affecter le technicien ;
- enregistre les pices à reparer et à remplacer et estimation d'intervention en cas dehors garantie pour envoi à l'adv pour devis.
- suivre les réparations ;
- suivre les demandes de pièces ;
- suivre les réceptions import et les alertes techniques.

### Technicien

Rôle du technicien dans la plateforme :

- recevoir les tickets affectés ;
- faire le diagnostic ;
- faire évoluer le ticket en réparation ;
- demander des pièces si besoin ;
- déclarer les pièces utilisées ;

### Magasinier

Rôle du magasinier dans la plateforme :

- traiter les demandes liées au dépôt principal ;
### Import

Rôle du service import dans la plateforme :

- recevoir les demandes d'achat import ;
- lancer les commandes ;
- confirmer la réception ;
### Facturation

Rôle de la facturation dans la plateforme :

- Effectuer le ticket d'entrée ;
- suivre l'historique des tickets liés à la facturation ;
- telecharger le ticket de sortie.

### Responsable appels d'offre

Rôle du responsable appels d'offre dans la plateforme :

- gérer les marchés ;
- gérer les équipements sous marché ;
- planifier les visites préventives ;
- gérer les visites correctives ;
- suivre l'historique des marchés.

### Admin

Rôle de l'admin dans la plateforme :

- superviser toute la plateforme ;
- consulter le détail global des tickets ;
- suivre les pièces, marchés et visites ;
- suivre les tickets clôturés ;
- gérer les acteurs et clients ;
- consulter les messageries internes et fournisseurs.
