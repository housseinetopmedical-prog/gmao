Ce dossier contient l'organisation generale des espaces de la plateforme.

Ce que l'on trouve ici :

- `layout.tsx` : la structure commune des espaces connectes
- `page.tsx` : la porte d'entree qui redirige selon le role
- `tableau-de-bord.module.css` : les styles communs de certains tableaux de bord
- `(espaces)` : les vrais espaces metier visibles dans la plateforme
- les autres dossiers entre parentheses : anciens regroupements techniques conserves pour compatibilite

Important :

- les dossiers entre parentheses servent a ranger le code ;
- ils ne changent pas l'adresse visible de la page ;
- il faut donc les manipuler avec prudence.

Resume simple :
- ce dossier sert a organiser les espaces internes sans changer le fonctionnement visible
