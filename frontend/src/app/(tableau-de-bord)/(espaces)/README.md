Ce dossier contient les espaces principaux utilises par les personnes qui travaillent sur la plateforme.

Chaque sous-dossier correspond a un vrai espace visible dans l'interface :

- `admin`
- `adv`
- `appels-offre`
- `client`
- `facturation`
- `import`
- `magasinier`
- `responsable-technique`
- `technicien`

Ici, on range le code par metier.
Le but est de retrouver plus facilement les pages de chaque role.

Resume simple :
- un dossier = un espace metier visible dans la plateforme
